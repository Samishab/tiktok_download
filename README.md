# Video Downloader (TikTok / YouTube)

برنامج لتحميل فيديوهات تيك توك (فيديو أو حساب كامل) وفيديوهات قناة يوتيوب، مبني على yt-dlp.

## التشغيل من المصدر
```bash
pip install -r requirements.txt
python app.py
```

## ملف التشغيل (Windows)
يُبنى تلقائيًا عبر GitHub Actions. حمّله من تبويب Actions (Artifacts) أو من Releases عند وجود tag مثل `v1.0.0`.
للاستخدام الشخصي فقط، واحترم حقوق المحتوى وشروط المنصات.
